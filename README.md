## 📍 프로젝트 소개

> 코딩알려주는누나 리엑트 프로젝트<br>
> 프로젝트명: 도대체 어떤 인생을 살아온겁니까?<br>
> 프로젝트 기간: 2025.11.16 ~ 2025.11.23

올해도 얼마 남지 않았습니다. 다들 2025년 마무리는 잘 되가시나요?

매년 새해가 되면 습관처럼 새해 계획 또는 목표를 새우곤 합니다.<br>
**그러나 여러분 그 계획과 목표, 제대로 지키셨나요?** <br>
혹시 시도 조차 안하셨거나, 중간에 포기하신적은 없으신가요?

- 계획은 거창한데 당장 뭐 부터 해야 할지 모를 때,
- 구체적인 계획에 대한 우선 순위를 정하기 힘들 때
- 스스로와의 다짐을 꾸준히 지켜가며 갓생을 살고 싶을 때

저희 **`도대체 어떤 인생을 살아온겁니까?`** 를 통해 내년에는 좀 더
보람있고 빛나는 여러분의 삶이 되길 바라는 마음으로 서비스를 준비해봤습니다.

## 💡 기획 구조도

### 🎯 프로젝트 컨셉

사용자가 주어진 시간을 온전히 집중할 수 있도록 투두리스트를 제공하며
등록한 투두리스트를 쉽게 파악하기 위해 스케쥴러(캘린더)를 제공합니다.
또한 **주간/월간/연간 집중한 시간 및 완료한 할 일 등을 그래프로 보여줍니다.** 

### 🔀 사용자 플로우

메인 페이지 → 로그인/회원가입 → Todo List 등록 → 스케쥴러 확인 → 히스토리 확인

### 🔐 로그인 & 회원가입

![로그인/회원가입](https://github.com/user-attachments/assets/6ab88ee1-6886-424b-8188-80ae0cd761fa)

- 이름, 계정, 비밀번호 닉네임을 입력하여 회원가입이 가능합니다.
- 중복 방지 기능일 구현하여 이미 등록된 계정은 사용할 수 없습니다.
- 로그인한 사용자에 한하여 투두리스트 페이지 접근이 가능하며 투두리스트에서 로그아웃 시 다시 메인 화면으로 돌아갑니다.

### ✅ 투두 리스트

![투두리스트](https://github.com/user-attachments/assets/3017bafd-40f8-4bd8-a22e-8e7258c49e10)

- 투두리스트는 월별로 등록할 수 있습니다.
- 수정 삭제가 가능하며 완료한 투두리스트는 체크도 가능합니다.
- **날짜, 우선 순위, 등록한 투두리스트의 텍스트등을 분석하여 AI가 할일 순서를 추천해줍니다.**
